# TERMUX-X

أداة مفتوحة المصدر لتخصيص واجهة Termux وإدارة الثيمات وموجه الأوامر.

## المميزات
- ثيمات لونية جاهزة مع معاينة نصية.
- تخصيص موجه الأوامر بدل علامة `$`.
- شاشة ترحيب عند فتح Bash.
- معلومات أساسية عن الجهاز.
- نسخ احتياطي واستعادة تعديلات الأداة.
- إزالة آمنة للتخصيصات التي أضافتها الأداة.

## التثبيت
```bash
pkg update -y
pkg install git -y
git clone https://github.com/USERNAME/TERMUX-X.git
cd TERMUX-X
bash install.sh
source ~/.bashrc
termux-x
```

استبدل `USERNAME` باسم حساب GitHub بعد رفع المستودع.

## الإزالة
من مجلد المشروع:
```bash
bash uninstall.sh
```

## ملاحظات
- لا يحتاج Root.
- موجه الأوامر الحالي يطبّق على Bash. دعم Zsh يمكن إضافته لاحقاً.
- الثيمات هنا تخص ألوان وموجه الطرفية؛ لون خلفية تطبيق Termux والخط يتم ضبطهما من إعدادات التطبيق أو ملفات Termux المناسبة.
- خذ نسخة احتياطية قبل تعديل ملفات إعداداتك يدوياً.
